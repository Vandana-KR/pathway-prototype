# Pathway (Prototype)

A concept mobile app where companies post their hiring requirements and training roadmap, and candidates can register for free and train against it — either with a real trainer from the company, or through an AI-guided walkthrough.

This is a **portfolio/demo project**. All company data shown is fictional/sample data, not real companies.

## What it demonstrates
- Candidate flow: browse companies → view requirements & roadmap → register → track training progress
- Company flow: post a roadmap → view registered candidates
- A single self-contained HTML/CSS/JS file — no build step, no backend, runs entirely in the browser

## Try it
Open `index.html` in any browser, or view it live via GitHub Pages (see repo settings).

## Stack
Vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

## Status
Early-stage prototype built to test the product flow and UI before deciding on a real backend/framework (likely React Native for a production mobile version).
